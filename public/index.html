What is returned by Zoom, and what does this app calculate?

Zoom returns a choice and its probability distribution, plus two independent predicate probabilities. The app maps choice values to display labels and calculates uncertainty as 1 − the selected-choice probability. These probabilities are not guarantees of accuracy.

Rationale is a fixed app explanation of the selected route, not a model explanation. Evidence lists the supplied sources and independently requested predicates; it is not a citation or a causal explanation. Server latency covers the full Zoom HTTP request and response, including network time. Sample runs have no API latency.

Questions are independent. The app does not use the predicate answers to claim that they caused the route. Refusals and absent confidence fields are shown explicitly.

Connect to Zoom

The sample walkthrough runs immediately. For live results, obtain Decisions-enabled credentials from your Zoom AI Services project.

  1. Copy .env.example to .env in the project folder.
  2. Set ZOOM_API_KEY to your Decisions-enabled API key.
  3. Restart with npm start, refresh, and select Live Zoom API.

No credential is entered into or stored by this browser.

Documentation discrepancy: the API reference specifies x-api-key; the Fast mode guide shows Bearer authentication. This app defaults to the reference. If your project uses a token, set ZOOM_ACCESS_TOKEN instead. API key takes precedence.
